# CRAFTED MINDS

> **Ideas Crafted Into Digital Experiences.**

A premium, minimal, and sophisticated digital agency website engineered with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

---

## ✨ Features

- **Monochrome Glassmorphism UI**: High-fidelity frosted glass surfaces, backdrop blur, optical reflections, and deep black/charcoal aesthetic.
- **Hero Telemetry & Matrix**: Interactive glass composition showcasing design systems, live telemetry, and tech stack benchmarks.
- **Services Preview**:
  - Website Development
  - UI/UX Design
  - E-commerce Development
  - Website Maintenance
- **Selected Works**: Architectural case studies with performance metrics.
- **Team**: Architectural portrait cards for core architects & builders.
- **Interactive Free Demo Booking**: Glass dialog with service scope selection and instant confirmation.
- **Fully Responsive**: Fluid layout across all devices, mobile glass navigation drawer, and sub-second page performance.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the website.

To create a production build:

```bash
npm run build
```
